# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-07

### Added

- Azure Key Vault resource with configurable SKU, RBAC, purge protection, and soft-delete.
- Key management with RSA and RSA-HSM support and automatic rotation policies.
- Secret management with content types and expiration dates.
- Certificate management with self-signed and CA-issued certificate support.
- RBAC role assignments scoped to the Key Vault.
- Private endpoint with private DNS zone integration.
- Diagnostic settings with Log Analytics workspace integration.
- Network ACL configuration with IP rules and virtual network subnet rules.
- Basic, advanced, and complete usage examples.
